# Chinmayee Surwade | Analyst Portfolio

A recruiter-focused portfolio for Chinmayee Surwade, Business Analyst and Data Analyst.

## Stack
- Next.js 15
- React 19
- Responsive custom CSS
- Lucide icons

## Sections
- Hero and verified impact metrics
- About and core capabilities
- Professional experience
- Independent client work
- Technical and BA portfolio
- Skills and contact

## Local development
```bash
npm install
npm run dev
```

Client-sensitive information is intentionally excluded. Synthetic BA simulations are presented separately from real professional and consulting experience.
